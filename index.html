イヌlog サポート

愛犬との毎日を記録するアプリ「イヌlog」のサポートページです。

お問い合わせ・不具合のご報告
GitHub の Issues からお知らせください。公開の場になるため、個人情報や愛犬の記録の内容は書かないでください。機種（iPhoneの型番）とiOSのバージョン、起きたこと、できれば画面のスクリーンショット（個人情報を隠したもの）を添えていただけると助かります。

よくある質問

購入について

無料で使える範囲は？
イベントとマップは無料です。散歩・カルテ・Apple Watch連携は、月額プラン（最初の1か月無料）か買い切りで使えます。

月額プランの解約方法は？
iPhoneの「設定」→ 自分の名前 →「サブスクリプション」→「イヌlog」から、いつでも解約できます。無料期間中に解約すれば料金はかかりません。

機種変更したら？
購入画面の「購入を復元」から、同じApple IDの購入を引き継げます。

記録について

記録はどこに保存されますか？
すべてお使いの端末の中です。開発者のサーバーには送信されません。アプリを削除すると記録も消えるため、機種変更の前にご注意ください。

血液検査の用紙の読み取りがうまくいきません
表の部分が画面いっぱいに、まっすぐ明るく写るように撮影してください。読み取り結果は保存前に必ず用紙と見比べてください。読み取れない書式の用紙があれば、Issues でお知らせください。

血液検査の「考えられること」は診断ですか？
いいえ。数値の一般的な読み方に基づく参考情報です。気になる結果は獣医師にご相談ください。

イベントが載っていません
イベント情報は外部の掲載情報をもとにしています。載っていないイベントは、イベント画面の虫めがね（Webで探す）から探して追加できます。
